🚀 COMMENT DÉMARRER
═══════════════════════════════════════════════════════════════════════════

Option 1 - SCRIPT AUTOMATIQUE (Recommandé) ⭐
────────────────────────────────────────────

  Unix/Linux/Mac:        Windows:
  ./start.sh             start.bat

Option 2 - MANUEL
─────────────────

  Terminal 1 - Backend:
  $ cd backend
  $ python -m venv venv
  $ source venv/bin/activate    # Windows: venv\Scripts\activate
  $ pip install -r requirements.txt
  $ python main.py
  
  Terminal 2 - Frontend:
  $ cd frontend
  $ npm install
  $ npm run dev

Option 3 - AVEC NPM
───────────────────

  À la racine:
  $ npm install
  $ npm run dev
