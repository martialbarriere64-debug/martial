# 🤝 Guide de contribution à ImmoGlam

Merci de votre intérêt pour contribuer à ImmoGlam ! Ce guide vous aidera à démarrer.

## 🚀 Démarrage rapide

1. **Fork** le projet
2. **Clone** votre fork
3. Créez une **branche** pour votre fonctionnalité : `git checkout -b feature/ma-feature`
4. **Commitez** vos changements : `git commit -m 'Ajout de ma feature'`
5. **Push** vers la branche : `git push origin feature/ma-feature`
6. Ouvrez une **Pull Request**

## 📝 Standards de code

### Backend (Python)

- Suivez les conventions **PEP 8**
- Utilisez des **docstrings** pour toutes les fonctions
- Ajoutez des **commentaires** pour les logiques complexes
- Testez votre code avant de commit

### Frontend (React)

- Utilisez des **composants fonctionnels** avec hooks
- Nommez les composants en **PascalCase**
- Utilisez **TailwindCSS** pour le styling
- Gardez les composants **petits et réutilisables**

## 🐛 Signaler des bugs

Utilisez les **GitHub Issues** avec le template suivant :

```
**Description du bug**
Une description claire du bug.

**Étapes pour reproduire**
1. Aller sur '...'
2. Cliquer sur '...'
3. Le bug apparaît

**Comportement attendu**
Ce qui devrait se passer.

**Captures d'écran**
Si applicable.

**Environnement**
- OS: [ex: macOS]
- Browser: [ex: Chrome]
- Version: [ex: 1.0.0]
```

## ✨ Proposer des fonctionnalités

Ouvrez une **issue** avec le label `enhancement` et décrivez :
- Le problème que ça résout
- La solution proposée
- Des alternatives envisagées

## 🧪 Tests

Avant de soumettre une PR :
1. Testez le backend : vérifiez que l'API fonctionne
2. Testez le frontend : vérifiez l'interface utilisateur
3. Testez l'intégration complète

## 📚 Documentation

Si vous ajoutez des fonctionnalités, mettez à jour :
- Le README.md
- Les commentaires dans le code
- La documentation API si nécessaire

## 🙏 Merci !

Chaque contribution compte, qu'elle soit petite ou grande. Merci de faire partie de la communauté ImmoGlam !
